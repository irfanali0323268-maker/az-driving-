AZ DRIVING SCHOOL - LOCAL RUN
  python3 -m http.server 8000   then open http://localhost:8000   (must be served from the project root)
Edit content in build.py, then run: python3 build.py   (rewrites every page, sitemap.xml, robots.txt, _redirects, _headers)

URLS
Pages are folders (about-us/index.html -> https://azdriving.co.uk/about-us/) so clean URLs, canonicals,
internal links and sitemap all match on ANY static host. _redirects (Netlify/Cloudflare Pages) 301s the old .html URLs.
_headers adds security + long-cache headers.

SEO - BEFORE GOING LIVE
1. Confirm postcode GL1 4LR, phone and email (used in schema, footer, contact).
2. Search Console: add the verification meta tag (comment in <head>), submit sitemap.xml,
   then request indexing for: /, /about-us/, /driving-courses/, /pricing/,
   /driving-theory-test/, /success-stories/, /faqs/, /contact/
3. Bing Webmaster Tools: same, add msvalidate.01 tag.
4. Google Analytics 4: paste your gtag snippet in the <head> comment.
5. Create/verify your Google Business Profile with the SAME name, address and phone.
6. Test schema at search.google.com/test/rich-results and validator.schema.org.
7. Add real reviews and Facebook/Instagram links to sameAs in build.py (BIZ) when available.
Not claimed: ratings, awards, opening hours, indexing status.

DEPLOY ON VERCEL (static site, no build step)
Option A - Dashboard (easiest):
  1. Put this folder in a GitHub/GitLab repo (build.py, README.txt and zips are excluded by .vercelignore).
  2. vercel.com > Add New > Project > import the repo.
  3. Framework Preset: Other.  Build Command: leave empty.  Output Directory: leave empty (project root).  Install Command: leave empty.
  4. Deploy. Then Project > Settings > Domains > add azdriving.co.uk and www.azdriving.co.uk
     (set www to redirect to azdriving.co.uk so canonical URLs stay consistent).
Option B - CLI:  npm i -g vercel  then, inside this folder:  vercel --prod
vercel.json (auto-generated by build.py) sets: clean URLs + trailing slashes (/pricing/), 301s for old .html URLs,
security headers, long caching for /assets, style.css and app.js, and correct content types for sitemap, llms.txt and the manifest.
404.html is served automatically for unknown URLs. _headers and _redirects are only for Netlify/Cloudflare and are ignored on Vercel.
After changing content: edit build.py, run  python3 build.py,  commit and push - Vercel redeploys automatically.

CONTACT FORM -> EMAIL (info@azdriving.co.uk)
The form posts to /api/contact/ (api/contact.js, a Vercel serverless function) which emails you through Resend.
Setup (one time, ~10 minutes):
  1. Create a free account at resend.com > Domains > Add azdriving.co.uk, add the DNS records it shows, wait for "Verified".
  2. Resend > API Keys > Create API Key.
  3. Vercel > Project > Settings > Environment Variables: add RESEND_API_KEY = (the key). Optional: MAIL_TO, MAIL_FROM.
  4. Redeploy. Test the form on /contact/ - the enquiry arrives in info@azdriving.co.uk; pressing Reply answers the customer.
If sending ever fails, the customer sees your phone, WhatsApp and email instead of losing the enquiry.

INTRO ANIMATION
The animated logo plays full screen once per browser session (about 3.4 s), has a Skip button / Esc key,
and is skipped for reduced-motion users and search-engine bots. The site then fades in.

GOOGLE LOGO / FAVICON + SITELINKS (do these after deploying)
- Icons: favicon.ico (16/32/48) + assets/icon-48/96/144/192/512.png, all the new AZ logo. Google only re-reads favicons when it re-crawls
  the HOMEPAGE, so the old icon stays in search results for days to a few weeks. Speed it up:
  Search Console > URL Inspection > https://azdriving.co.uk/ > Test Live URL > Request Indexing.
  Check https://azdriving.co.uk/favicon.ico and /assets/icon-48.png open in a browser (they must not redirect or be blocked).
- Search Console: add property (Domain), paste the verification meta tag into build.py's <head> comment, run build.py, deploy, Verify,
  then Sitemaps > add sitemap.xml. Request indexing for each page listed above.
- Sitelinks (the extra links under the result) are chosen automatically by Google. They appear once the site is indexed and trusted; clear nav
  names, SiteNavigationElement schema, internal links and a complete sitemap (all done) give the best chance. They cannot be forced.
- Biggest ranking lever for "driving school Gloucester": a verified Google Business Profile with the same name/address/phone, real reviews,
  and consistent listings (Bing Places, Yell, Facebook).

BLOG
Posts live in blog_data.py (title, SEO title, description, image, body HTML). Add a post by copying one entry, then run python3 build.py.
Each post gets its own page /blog/<slug>/, BlogPosting + Breadcrumb schema, sitemap entry, llms.txt entry and a card on /blog/ and the homepage.
Update fees in the posts (theory GBP23, practical GBP62/GBP75, provisional GBP34) if GOV.UK changes them.
